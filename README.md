## 📂 Projetos em Destaque

### 📱 Seriando (Em Desenvolvimento)
> Aplicativo Android nativo para acompanhamento de séries e filmes. Conta com autenticação Google via Firebase, consulta de dados via TMDB API, controle de progresso de episódios, listas personalizadas e módulo comunitário para avaliações, opiniões com marcadores de spoiler e seleção de emoções.  
`Kotlin` • `Jetpack Compose` • `Firebase Auth & Firestore` • `TMDB API` • `Android Studio`

### 📄 PDF to Markdown (V1)
> Aplicação desktop para seleção de arquivos PDF via interface gráfica e conversão automatizada do conteúdo textual para formato Markdown (`.md`), organizando as saídas em diretório dedicado.  
`Python` • `PyMuPDF` • `Tkinter` • `Pathlib`

### 🎬 Media Downloader
> Aplicação desenvolvida em Python para download automatizado de vídeos e áudios utilizando `yt-dlp` e `FFmpeg`, integrando suporte a múltiplos formatos e unificação de mídia.  
`Python` • `yt-dlp` • `FFmpeg` • `CLI`

### 🏦 Sistema Bancário
> Aplicação orientada a objetos (POO) simulando fluxos bancários reais: cadastro de clientes, contas correntes, histórico de transações, saques e depósitos.  
`Python` • `POO` • `Boas Práticas`

### 📊 Análise de Dados com Interface Gráfica
> Ferramenta Desktop para importação e leitura de dados em formato CSV com plotagem dinâmica de relatórios visuais.  
`Python` • `Pandas` • `Matplotlib` • `Tkinter`

### 🌐 Web Scraper
> Script de automação para extração e estruturação de dados de páginas web.  
`Python` • `BeautifulSoup` • `Web Scraping`
