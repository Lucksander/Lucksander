## 📂 Projetos em Destaque

### 🏦 Sistema Bancário

Sistema bancário desenvolvido com Programação Orientada a Objetos (POO), permitindo cadastro de clientes, criação de contas, depósitos, saques e consulta de saldo.

### 🎮 Jogo da Forca

Jogo completo com categorias de palavras, arte ASCII, sistema de pontuação, bônus por acerto completo e menu interativo.

### 🇧🇷 Validador de CPF

Implementação do algoritmo oficial de validação de CPF com aplicação prática em sistemas de cadastro e validação de dados.

### 🔐 Gerador de Senhas

Aplicação para geração de senhas aleatórias utilizando letras, números e caracteres especiais.

### 📊 Análise de Dados

Projeto utilizando Pandas, Matplotlib e Tkinter para leitura de arquivos CSV e geração automática de gráficos.

### 🌐 Web Scraper

Aplicação para coleta automatizada de informações de páginas web utilizando Python.

### 📄 Leitor de Arquivos TXT

Sistema para seleção e leitura de arquivos de texto utilizando Tkinter.
